# Contributing to Cratepin

These guides are for contributors and coding agents changing Cratepin's source code. You do
not need to read them to use the tool in your project. For installation and usage, start with
the [product documentation](../README.md) and [CLI/API recipes](../recipes.md).

- [Development guide](development.md): setup, repository layout, safety invariants and review.
- [Source layout](source-layout.md): module groups, entry points and colocated tests.
- [Repository scripts](scripts.md): npm commands, shared modules and local experiments.
- [Code quality](code-quality.md): required checks, coverage floors and structural limits.
- [Coding style](coding-style.md): naming, modules, TypeScript and I/O conventions.
- [Testing strategy](strategy.md): behavior, fault injection and platform evidence.
- [Media quality contracts](media-semantics.md): pixel semantics and lossy tolerances.
- [Visual review](visual-review.md): reviewing generated comparison samples.

Root `AGENTS.md` and `CLAUDE.md` direct coding agents here. Task-specific instructions and
optional local context supplement these shared contribution rules.
